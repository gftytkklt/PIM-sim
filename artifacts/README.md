# 运行产物

此目录用于本地运行输出，生成文件不随源码分发。

| 子目录 | 内容 |
|---|---|
| `logs/` | C++ 和 Python 日志 |
| `cache/` | 分析缓存、绘图库缓存 |
| `results/` | 图表和导出结果 |
| `runs/` | 分析运行配置、流量文件和结果 JSON |
| `tests/` | 测试及跨构建事件轨迹 |

`PIM_ARTIFACTS_DIR` 覆盖日志、缓存、结果和运行目录的默认根路径；显式命令行输出路径仍使用给定值。请为需要保留的实验选择不同输出路径。目录和入口说明见[项目布局](../docs/guides/project-layout.md)。
